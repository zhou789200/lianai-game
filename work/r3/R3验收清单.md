# R3 验收清单

版本：V1.0
日期：2026-10-13
任务编号：R3-01（供 R3-03 QA 执行、R3-04 主线终验）

用例格式：`编号 | 前置条件 | 步骤 | 预期结果 | 证据类型 | 阻断级别`

- 证据类型：`脚本`（自动化）、`截图`、`录屏`、`控制台`、`人工`
- 阻断级别：`P0`（阻断，必须修复才能过 R3）、`P1`（严重，R3 结束前修复）、`P2`（一般，登记后可延期）

## 1. R3-FUNC 功能用例

### R3-FUNC-01 开始营业
| 项 | 内容 |
|---|---|
| 前置 | 准备页可见，体力 ≥4，金币/经验有初始值 |
| 步骤 | 1. 进入咖啡店入口 2. 点击「开店营业」 |
| 预期 | 体力 -4；进入 opening；倒计时 150s 开始；底部导航消失 |

## 2. R3-RECOV 恢复与边界用例

### R3-RECOV-01 错误放置恢复
| 前置 | 拿着任意原料/成品 |
| 步骤 | 拖到错误设备释放 |
| 预期 | 弹回原处 + 抖动；原料不销毁、不消耗；订单状态不变 |
| 证据 | 脚本 + 录屏 | P0 |

### R3-RECOV-02 长按超差补救
| 前提 | 咖啡机萃取中 |
| 步骤 | 1. 长按 899ms 松手（不足）2. 选择重做 3. 选择直接采用 |
| 预期 | 超差提示出现；重做回退步骤且不扣金币；采用则满意度 -20 继续链条 |
| 证据 | 脚本 | P0 |

### R3-RECOV-03 上错桌取回
| 前置 | 托盘拖到错误桌 |
| 步骤 | 1. 3s 内取回 2. 再上正确桌 3. 重复但等 4s |
| 预期 | 3s 内可取回无惩罚；超时该单满意度 -30，成品仍可上正确桌 |
| 证据 | 脚本 | P1 |

### R3-RECOV-04 订单超时
| 前置 | 顾客 waiting 且耐心耗尽 |
| 步骤 | 不处理该订单直至耐心归零 |
| 预期 | 顾客 left；无收入；ordersTimeout+1；无金币/体力惩罚；完美判定取消 |
| 证据 | 脚本（mock 时钟） | P0 |

### R3-RECOV-05 暂停与失焦
| 前置 | 营业 running |
| 步骤 | 1. 打开离店确认 2. document.hidden 3. window.blur 4. 恢复 |
| 预期 | 三种场景全部 paused：倒计时、耐心、设备进度冻结；恢复后从冻结点继续 |
| 证据 | 脚本 + 录屏 | P0 |

### R3-RECOV-06 离店确认
| 前置 | 营业 running |
| 步骤 | 点击关闭 → 选「继续营业」/「结束并结算」各一次 |
| 预期 | 继续则无事发生；结束则走 closing→settled 正常结算已得收益 |
| 证据 | 脚本 | P0 |

### R3-RECOV-07 刷新恢复
| 前置 | 营业中已完成 3 单 |
| 步骤 | 浏览器刷新 |
| 预期 | 回到准备页；已完成 3 单的金币/经验/统计保留（localStorage）；体力不重复扣；营业中会话丢弃 |
| 证据 | 脚本 + 控制台 | P0 |

### R3-RECOV-08 重复结算防护
| 前置 | 结算页已出 |
| 步骤 | 1. 快速双击「领取/确定」 2. 脚本连续调用 settleSession 两次 |
| 预期 | 完美奖励与目标奖励只发一次；businessRuns 只 +1 |
| 证据 | 脚本 | P0 |

### R3-RECOV-09 切换页面防后台计时
| 前置 | 营业中（若实现允许切页） |
| 步骤 | 强制切到其他 view 再回来 |
| 预期 | 离开即暂停，回来不补时；无「后台偷偷跑完」 |
| 证据 | 脚本 | P1 |
