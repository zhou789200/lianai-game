## 1. 营业时间轴（150 秒标准局）

| 时间点（秒） | 事件 | 数值 |
|---|---|---|
| 0.0 | `opening`，2 位顾客进店 | 类型按权重抽取 |
| 1.5 | 首批顾客 `seated` → `running` | — |
| 2.3 | 首批订单生成（各桌 0.8s 点单） | 订单 1、2 |
| 15 | 首个事件槽 | 顾客/设备事件 |
| 15–60 | 上手期：第 3、4 位顾客到店（间隔约 20s） | 订单 3、4，含 1 个偏好要求 |
| 60–120 | 高峰期：第 5–8 位顾客（间隔 12–15s），并行订单 3–4 份 | 订单 5–8 |
| 60–120 | 角色事件窗口 `characterVisit` | 每会话 ≤1 次 |
| 120–150 | 收尾期：不再进新客；布丁日记/最后事件 | 最后下单截止 = 135s |
| 150 | `closing` | — |
| 150–170 | 收尾（清桌/完成在制订单），20s 强制截止 | — |
| ≤171 | `settling` → `settled`（动画 ≤1s） | — |

- 顾客总数：6–8 位（4 桌轮换，顾客离开释放桌位）。
- 订单总数 `ordersTotal`：6–10 份（含双份 qty=2）。
- 首次营业（dayIndex=1）可跳过教学，但首批订单固定为 2 份海盐拿铁（最短链）。

## 3. 经济数值

### 3.1 配方收入

| 配方 | 基础收入 | 小费区间 | 经验 | 完美判定 |
|---|---:|---|---:|---|
| 海盐拿铁 | 18 | 2–8 + tipBonus | 3 | 满意度 ≥90 |
| 黄油可颂 | 22 | 2–8 + tipBonus | 4 | 同上 |
| 柑橘气泡水 | 26 | 3–10 + tipBonus | 4 | 同上 |

- 满意度计算：`satisfaction = typeDef.satisfactionBase − 等待扣减 − 瑕疵扣减 + 偏好奖励`。
  - 等待扣减：`waiting` 阶段每超过该类型耐心 50% 的 10s，-10（下限 -30）。
  - 瑕疵扣减：使用 `imperfect` 产物 -20/-25/-15（见内容配置 §1）。
  - 偏好奖励：正确完成偏好 +10。
- 小费公式：`tip = tipMin + round((tipMax − tipMin) × satisfaction / 100) + tipBonus(事件) + tipBonusFlat(招牌)`；`satisfaction < 40` 时小费为 0。
- 清桌小费：+2 金币/桌（`CLEAN_TIP_BASE`）。
- 双份订单：基础收入与小费 ×2，交互只增加关键手势（萃取/注入按两次）。

## 4. 空档提示（无操作 8 秒）

| 规则 | 值 |
|---|---|
| 触发 | `now − session.lastActiveAt ≥ 8000ms` 且 `paused === false` 且存在可做动作 |
| 冷却 | 两次提示间隔 ≥12s（`idleHintShownAt`） |
| 提示选择优先级 | 1) 存在 `new` 订单 → 「有客人在等接单」 2) 存在 `dirty` 桌 → 「把桌子擦一擦，还有小费」 3) 存在 assembled 成品 → 「这份可以上桌了」 4) 托盘/设备空闲 → 「提前把杯子放好、补个货」（补货动作 +2 金币，每会话 ≤3 次） |
| 表现 | 操作提示条高亮 + 抖动，不弹窗打断 |

## 5. 失败只影响小费与评价（不卡主线）

| 失败场景 | 后果 | 明确不发生 |
|---|---|---|
| 订单超时（顾客 left） | 无该单收入/小费，满意度不计，`ordersTimeout +1` | 不扣金币、不扣体力、不降店铺等级 |
| 长按超差且采用瑕疵品 | 满意度 -15~-25，小费可能归零 | 不判订单失败 |
| 上错桌超 3s | 该单满意度 -30 | 不销毁成品（拿回后仍可上正确桌） |
| 重做步骤 | 消耗原料（免费），+1 次交互 | 不消耗金币（retryCostCoins=0） |
| 全部顾客离店 | 提前进入 closing，正常结算已得收益 | 不发惩罚 |
| 刷新丢失会话 | 体力不返还 | 不重复扣（体力只在 startSession 扣一次） |

## 6. 与现有系统的最小兼容规则

| 系统 | 规则 |
|---|---|
| 金币 | 沿用 `GameState.coins`；每单即时 `serveOrder` 入账；结算只补完美/目标奖励 |
| 体力 | 只在 `startSession` 扣 4；R3 不引入营业内体力机制 |
| 经验 | 沿用 `serveOrder` 的 exp 与 `expForLevel` 升级逻辑 |
| 宠物 | 打烊日记 push 进 `PetState.diary`（上限 40 条，沿用现有 slice）；`catLover` 事件不加亲密度，打烊日记时亲密度 +1（每会话 1 次，走 `petAction` 之外的轻量路径，复用 clamp） |
| 关系 | `characterVisit` 结算时 `Relationship.value +2`，clamp 0–100，每会话 ≤1 次 |
| 任务 | `serve_orders` / `open_shop` / `upgrade_once` 沿用现有 `bumpTasks` 路径 |
| 存档 | 不改 `SAVE_VERSION`；新增字段全部在运行时会话，不进 `GameState` |
