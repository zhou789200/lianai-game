## 10. 复测后追加互动：点小猫会叫会歪头（2026-10-15）

**需求（用户反馈）**：宠物页点小猫要有互动——猫会叫、头会动。

**音频方案**：项目里没有任何音频文件，也没有音频生成工具链，因此不引入外部素材，改为 **Web Audio 现场合成**：新增 `app/src/game/petVoice.ts`，用锯齿波 + 三角波走音高轮廓（起音略低 → 上扬 → 收尾下滑），过两个带通共鸣腔做出「喵」的元音，再叠 19Hz 颤动，收成 0.4–0.5s 的一声猫叫；每次点击基频在 380–560Hz 间随机，所以叫声不呆板。浏览器要求音频由用户手势启动，点小猫本身就是那个手势。连点按挂钟限流 350ms，避免糊成噪音。

**动作方案**：

1. `app/src/views/PetView.tsx`：立绘区从 `<div>` 改成 `<button aria-label="摸摸布丁，它会叫一声">`（键盘可达）；点击触发 `playMeow()` + 反应状态。
2. `app/src/styles/views.css`：新增 `.pet-hero__body`，`transform-origin: 50% 16%` 把旋转支点放在脖子附近，配 `pet-meow` 关键帧（-5.5° → 4.5° → -3° → 2° → 0°）做出歪头；呼吸动画留在内层 `<img>`，两层变换互不打架；`key` 跟着点击序号变，保证每次都重播。
3. 反馈层：头顶飘一个「喵～ / 咪—— / 喵呜 / 呼噜呼噜 / 喵！」气泡（1.6s 自动收尾），同时浮三颗小心，状态条上换成对应短句（例：布丁踩了踩你的手背）。文案不连续重复同一句。
4. 难度与数值：撸猫**不消耗体力金币、不改数值**（避免和「玩耍」动作的经济产生重复收益），底部那张「玩耍」卡片仍是唯一的加亲密度入口。

## 11. 复测后追加：猫叫更灵动 + 声音总开关（2026-10-19）

**需求（用户反馈）**：猫叫要更灵动活泼；再加一个声音总开关。

### 11.1 四种语气与更“活”的音色

`app/src/game/petVoice.ts` 重写，`scheduleMeow(ac, at, kind, detune)` 支持四种语气：

| kind | 听感 | 基频走向 | 时长 |
|---|---|---|---|
| `bright` | 开心长喵 | 520 → 840 → 500Hz | 0.36s |
| `chirp` | 短促「咪」 | 660 → 1080 → 820Hz | 0.20s |
| `double` | 连叫两声 | 560→780→600 + 700→1000→660Hz | 0.20s + 0.055s 间隔 + 0.16s |
| `soft` | 低落轻喵 | 360 → 430 → 300Hz | 0.52s |

音色做法从「锯齿波 + 两个带通」升级为：周期性波形（基波 + 2/3/4 次泛音）做声带；低通 900Hz → 5kHz 做出张嘴的「m→ow」；两个共鸣腔随音高滑动、结尾滑向「ou」；颤音深度从 0 渐深，尾音才有猫叫那种拐弯；最后过一层轻微压限，连叫不爆音。每次点击再叠 ±5% 随机移调，同一种语气也不会一模一样。

**语气跟着状态走**（`PetView`）：饿 → `double`（连叫两声）；心情低 → `soft`；心情 ≥70 → `bright`；其余 → `chirp`。

### 11.2 声音总开关

- 新增 `app/src/game/sound.ts`：开关存在独立的 localStorage 键 `seabreeze-pet-cafe.sound`（`on`/`off`），**不写进游戏存档**，所以「重置存档」不会顺手把静音选择重置掉；修改时派发 `seabreeze:sound-change`，已打开的界面同步更新。
- `playMeow()` 第一步就检查开关，关闭时直接返回、**不创建任何音频节点**（不是把音量调到 0）。
- 设置弹窗新增一行开关（`aria-pressed`、`Volume2`/`VolumeX`、滑动式 toggle）：`声音 / 小猫叫声与互动音效已开启`，关闭后文案变 `已静音，点小猫只保留动作`；重新打开时会试听一声短促的「咪」。

## 12. 复测后玩法手感优化：顾客气泡与满足感（2026-10-19）

## 13. D1/D2 修复与复测（2026-10-19）

### 13.1 D1：加工品质不足/过度后的恢复

加工时长未落在目标窗口时，营业页不再无声丢弃当前工序，而是弹出品质恢复面板，展示瑕疵类型和「满意度 -20 / -25 / -15」的后果，并提供两个明确选择：

- **倒掉重做**：释放当前设备、清除这份瑕疵品、不扣金币和体力，步骤保持在本工序，可直接重新加工。
- **直接采用**：保留瑕疵成品并推进到下一步骤，记录对应配方的满意度扣分（海盐拿铁 -20、黄油可颂 -25、柑橘气泡水 -15），后续仍可完成组装和装盘。

复测覆盖不足与过度两种时机，以及重做后设备可再次长按加工。恢复面板出现时步骤不会误推进；采用后步骤推进、成品可继续装盘。

### 13.2 D2：上错桌后的 3 秒取回

成品拖到错误桌位后，桌位和托盘同时提供取回入口，并进入 3 秒恢复窗口：

- 3 秒内取回：成品回到托盘，不扣满意度；可继续送到正确桌位。
- 超过 3 秒：错误桌拒收，成品保留在托盘，顾客满意度 -30，并显示明确提示。
- 最终送达：正确桌位正常上菜，评分原因中保留「上错桌 -30」，金币与小费结算照常执行。
